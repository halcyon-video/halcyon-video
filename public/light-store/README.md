# Full-quality comparison

`full-quality.webp` is a compressed screenshot of the actual Halcyon store,
captured on 2026-09-08 at high quality with the existing screenshot harness
from a development worktree without user assets. It depicts the full renderer
with its demonstration library; it is not generated artwork or a promise of
this appearance on every device.

The lightweight prototype requests this image only when the visitor opens
**See full quality**. Its bundled movie catalog and low-resolution poster
requests are independent of this illustrative full-store view.
