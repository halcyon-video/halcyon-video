# Flycam presentation

`flycam.mp4` is a silent two-take tour captured from the running application at development revision `a9581070a31526fc2212ac0b6cfc29955fb148ef`. It uses the existing Reel Recording Mode and F9 recorder, with automated keyboard flight: sunset storefront followed by an interior aisle. The app uses its original public assets and illustrative demo stock; this is not footage of a personal library or a published release.

The existing ffmpeg tool trimmed and joined the recorded takes, encoded H.264 at 1280 × 720, and validated the complete cut by decoding it. The output contains 350 frames over 14.583 seconds, with a 24 fps encoding time base. That encoding rate is not a claim about measured application performance.

Artwork attribution is in [demo poster attribution](../../public/demo-posters/ATTRIBUTION.md); the bundled overhead-TV clip is credited in [its attribution](../../public/demo-clip/ATTRIBUTION.md). No audio, account data, private branding skins, streaming-service logos or live movie streams were recorded.
