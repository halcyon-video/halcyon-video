# Compatibility and support marks

These official assets identify supported connections and the optional donation destination. They are separate from Halcyon Video's own identity and do not indicate endorsement. They are not relicensed under the application's GPL.

- Jellyfin: [official UX assets](https://github.com/jellyfin/jellyfin-ux/blob/master/branding/SVG/icon-transparent.svg), used beside the service name and link for interoperability under [Jellyfin branding guidance](https://jellyfin.org/docs/general/contributing/branding/). It is not the Halcyon logo.
- Plex: [official website logo](https://www.plex.tv/wp-content/themes/plex/assets/img/plex-logo.svg), used solely to identify compatibility and link to Plex. The README rendering preserves the mark on a dark field with surrounding clear space; the original SVG is retained unchanged. Plex and the Plex logo are trademarks of Plex and used under a license. See [trademarks and guidelines](https://www.plex.tv/en-au/about/privacy-legal/plex-trademarks-and-guidelines/) and [brand identity](https://brand.plex.tv/). Keep the mark unaltered and less prominent than Halcyon's identity.
- Emby: [official website asset](https://emby.media/resources/logo-dark-text.png), used solely to identify the Emby Server connection. [Emby Team guidance](https://emby.media/community/topic/50879-logo-usage-guidelines/) permits identifying a connection without implying the application was created by Emby.
- Ko-fi: official “Support me on Ko-fi” button from the [creator kit](https://more.ko-fi.com/brand-assets), linked to the same owner page as the app's tip jar: https://ko-fi.com/halcyonvideo. The downloaded AVIF was converted losslessly to PNG with ffmpeg for README compatibility; its design and proportions are unchanged. See [usage guidance](https://help.ko-fi.com/hc/en-us/articles/360011282254-Ko-fi-logos-buttons-stickers-and-shareables).

No streaming-provider marks are included.
