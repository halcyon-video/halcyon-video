# Halcyon Video 0.30.1

A fix release: game rentals now start in the desktop app, and phones get into the store faster.

- Renting an EmulationStation game now starts the game in the desktop app as well as in the browser. In 0.30.0 the desktop app's security rules blocked the player.
- Phones reach a usable store sooner: the first view prepares only the fixtures it shows, and shelf lighting compiles faster, with full textures, lighting and shadows kept.
- An inspected movie box stays visible while it turns over.
- The entrance gumball machine has a round glass globe, and its candy is drawn far more cheaply.
