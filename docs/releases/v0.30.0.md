# Halcyon Video 0.30.0

The games department opens up to libraries you already have, and big collections finally shelve fairly.

- Point the games department at an EmulationStation folder (ES-DE, Batocera, RetroPie) and each system becomes its own aisle, stocked with the box art you already scraped. Nothing is uploaded and no game server, account or key is needed.
- Rent an EmulationStation game to play it right in the browser, or get a plain note saying why it can't run.
- Large RomM libraries no longer shelve only games starting with A or B: each platform's whole list is ranked, best rated first, with unrated titles mixed in from across the alphabet.
- The tape return gains a Single slot style with one opening.
- Floor displays that had no real-store basis are gone.
- Phones enter the store sooner: the counter downloads first, bundled display faces ship smaller, and hosted models arrive compressed.
