# Halcyon Video 0.21.0

Steam libraries, alphabetical shelves, and a rebuilt front of store.

## What changed since 0.20.2

- Native Steam sign-in and owned-library refresh, exact review-category filtering, realistic or full-library shelving, and DVD packaging in every store era. On Linux, checking out a Steam game launches it while Halcyon suspends rendering, video and input; returning resumes the store. Steam integration is native-app-only.
- Optional alphabetical library organization, with natural title ordering and leading articles ignored.
- Reworked entrance, vestibule, exit preparation and return counter, checkout millwork, gates, recessed lighting, wall-aligned and 45-degree layouts, walking collisions, compact shelves and stocked clubhouse interior.
- New popcorn bins, candy gondolas, stocked beverage cooler and VHS cleaner merchandiser, plus optional freezer and secondary service-counter models. Sale stock, price cards, film-display backdrops, acrylic shelves, apparel and signage fit received corrections. The old trading-card promotion was removed.
- Staged startup shaders and optional model loading, batched static fixture geometry, instanced backstock, bounded poster uploads, and ambient occlusion during motion.
- A single tumbling rental clamshell screensaver; high-contrast episode and season selection; held Back to return a carried title; corrected flat-mode menu navigation; and a closed manager terminal during checkout handoff.
- Jellyseerr settings accept string-encoded ports. The private capture shortcut is Shift+C, with bounded capture images and help text matching the shortcut.

## Gallery

These are fresh captures of the release source using public Halcyon artwork, without private drop-ins or feedback pin images. Catalogue scenes use demonstration titles. The Steam controls show a disconnected UI fixture and the Steam case shows the public title Unpacking; neither exposes an account or an owned-game list. Optional models are labelled as asset-viewer studies. Phone images use browser emulation and do not establish physical-phone performance.
