# Halcyon Video 0.24.0

The store has new regulars: a second selectable clerk and ten original customers, alongside the existing clerk. Browsing also returns to the earlier shelf-height Steady camera, with a slightly closer view of the cases.

## In this release

- **Clerks and customers:** new large-eyed character designs, captured walking motion, interchangeable Polo and Oxford clerk uniforms, and brand-aware shirt colours. Choose a quiet rotating group of three regulars, all ten, or none. Characters use the existing fixture-aware paths and yield around visitors.
- **A clearer store:** restored Steady shelf framing, corrected entrance-frame overlaps, clearer storefront glass, fuller game shelves, and game navigation targets that match their actual shelf faces.
- **More convincing movement and surroundings:** improved clerk footfall and stocking poses, photographic commercial surroundings, and parking aligned with the exterior.
- **Browsing and startup:** an explicit SHELVES control on phones, touch overlays that retain their input focus, more readable synopsis text, startup progress for large catalogs, and more careful retirement of graphics resources. Netflix checkout uses exact movie links.

## Verification and remaining limits

The application build and all 1,128 unit tests pass. The Steady camera and entrance were also checked in the running store, including 160 camera checks across shelves, wall stock, displays and game fixtures.

Large catalogs and high-quality navigation can still be demanding. The broader navigation stress run exceeded the Windows development memory budget; this release does not establish a new phone performance target or claim that every device can render the store at high quality.

## Try it

[Open the browser store](https://halcyon-video.github.io/halcyon-video/) without a Halcyon account or media server. Streaming providers may require their own subscriptions and sign-in.

For your Jellyfin or Plex library, use the self-hosted app. The Docker release is `ghcr.io/halcyon-video/halcyon-video:0.24.0`.
