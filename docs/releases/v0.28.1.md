# Halcyon Video 0.28.1

A small release that keeps the shelves full and the controller listening.

- Libraries now pack bay by bay. Each library starts on the bay right after the last one the previous library stocked, so the walls no longer show empty bays between libraries. Any spare bays collect at the end of the floor.
- The Christmas tree standee on the 1990 aisle ends is now a real die-cut size instead of twice that, and its header support shrinks to match. On an aisle-end base the kit now faces the walkway where shoppers meet it.
- The built-in aisle-end plinths have rounded front corners and a white deck, with their seasonal front artwork kept.
- The store takes controller input whenever it is on screen, even when the window does not report keyboard focus, as happens in some full-screen and kiosk setups.
- With two controllers paired, the store follows the one you are actually holding instead of only ever reading the first. Polling also continues when a second paired controller goes to sleep.
- Remote Play no longer leaves old relay servers running after the store closes. Any stale relay from an earlier session is cleaned up the next time Remote Play starts.
